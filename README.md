## 🎨 Tentang Proyek

**Symphony-Sketchpad** adalah proyek web interaktif yang dirancang sebagai wadah eksperimen antara seni visual dan audio. Proyek ini memadukan konsep papan sketsa (*sketchpad*) dengan elemen musikal, memungkinkan pengguna untuk menikmati pengalaman kreatif yang dinamis langsung di dalam peramban web (*browser*).

---

## ✨ Fitur Utama

* **Papan Sketsa Interaktif** : Media visual untuk menuangkan ide dan kreativitas desain.
* **Integrasi Audio/Symphony** : Sentuhan elemen suara atau musik yang melengkapi pengalaman visual.
* **Antarmuka Minimalis & Modern** : Desain tata letak yang bersih, estetis, dan nyaman digunakan.
